# Stock Market Price Predictor 📈

This project predicts the **closing stock price** using historical data and **Linear Regression**.

## 🔍 Objective
To train a machine learning model to predict stock closing prices based on historical data.

## 📁 Files
- `AAPL.csv` – Sample stock data
- `stock_price_predictor.py` – Python code for prediction
- `stock_price_prediction_plot.png` – Output graph

## ⚙️ How to Run
```bash
pip install pandas numpy matplotlib scikit-learn
python stock_price_predictor.py
```

## 📊 Output
Displays model accuracy and plots **Actual vs Predicted** stock prices using test data.

## ✅ Model Used
- **Linear Regression** from `sklearn`
